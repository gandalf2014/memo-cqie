数据表结构概述

企业征信数据表包含超过50个字段，涵盖企业基本信息、经营状况、地理位置、时间维度等丰富数据，为多维度指标分析提供了坚实基础。

字段类别 代表字段 说明
企业标识 eid, reg_no, credit_no 企业唯一标识和各类代码
基本信息 name, category, econ_kind 企业名称、类型和行业类别
资本信息 regist_capi, actual_capi 注册资本和实收资本
时间信息 term_start, term_end, check_date 经营期限和批准时间
状态信息 status, new_status_code 企业当前经营状态
地理信息 province, longitude, latitude 企业所在地理位置信息

核心可视化指标体系

企业资本实力分析

分析各注册资本区间的企业数量分布，评估区域或行业的资本实力。

企业状态分布

展示在业、存续、吊销、注销等不同状态企业的比例，评估整体健康度。

重庆市区域分布

展示重庆市各区县的企业分布密度，识别经济活跃区域。

行业类型分布

分析各行业类型的企业数量分布，洞察区域经济结构特点。

重难点分析

数据质量挑战

数据类型不一致

注册资本等数值字段存储为字符串类型，包含非数字字符，需要复杂清洗。

时间格式混乱

日期字段存在多种格式，需要统一转换和标准化处理。

空值处理

关键字段存在大量空值，需要合理填充或排除。

技术实现难点

大数据性能

百万级数据量下，前端渲染性能需要优化，需采用聚合和采样策略。

指标计算复杂度

如实缴资本充足率等指标需要复杂计算和异常值处理。

数据一致性

同一企业多条记录需要去重，保留最新数据。

实战案例：重庆市巴南区高科技行业分析

案例背景

重庆市巴南区作为重庆市重要的工业基地和科技创新示范区，近年来高科技产业发展迅速。本案例通过对巴南区高科技企业的征信数据分析，评估该区域高科技产业的健康状况和发展趋势。

重庆市巴南区高科技企业经营稳定性分析

分析结论

  • 巴南区高科技企业数量稳步增长
  • 注册资本在1000万以上的企业占比28%
  • 实缴资本充足率达到72%，高于全市平均水平
  • 企业存活年限平均为6.8年
  • 年注销率维持在3.5%左右的健康水平
  • 主要集中在电子信息、智能制造领域

SQL查询示例

WITH cleaned_enterprise AS (
  SELECT
    eid,
    name,
    province,
    district_code,
    CAST(REGEXP_EXTRACT(regist_capi_new, '(\\d+)', 0) AS DOUBLE) AS regist_capi_clean,
    to_date(start_date, 'yyyy-MM-dd') AS start_date_clean,
    to_date(revoke_date, 'yyyy-MM-dd') AS revoke_date_clean,
    new_status_code,
    econ_kind,
    type_new
  FROM credit.db_enterpriset_enterprise
  WHERE province = '重庆市'
    AND district_code = '巴南区'
    AND (econ_kind LIKE '%科技%' OR type_new = '高科技')
)
SELECT
  new_status_code AS 企业状态,
  COUNT(eid) AS 企业数量,
  ROUND(COUNT(eid) / SUM(COUNT(eid)) OVER (), 4) * 100 AS 状态占比,
  AVG(regist_capi_clean) AS 平均注册资本,
  AVG(2023 - YEAR(start_date_clean)) AS 平均存活年限
FROM cleaned_enterprise
GROUP BY new_status_code
ORDER BY 企业数量 DESC;
