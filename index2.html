企业征信数据可视化指标构建知识分享

基于表 credit.db_enterpriset_enterprise 的结构，本文分享如何构建企业征信数据的可视化指标体系，涵盖重难点解析与实战案例。

一、数据表结构概览

该表包含企业基础信息、经营状态、法人信息、地理坐标、状态变更（吊销/注销）等字段，是构建企业信用画像的核心数据源。

关键字段分类如下：

  • 身份标识： eid, credit_no, name, format_name
  • 经营状态： status, new_status_code, revoke_date, logout_date
  • 资本信息： regist_capi_new, actual_capi, currency_unit
  • 法人信息： oper_name, oper_name_id, title_code
  • 地理信息： province, address, longitude, latitude
  • 时间维度： created_time, last_update_time, row_update_time

二、指标构建重难点解析

1. 数据质量与字段歧义

难点：字段命名混乱（如 regist_capi 与 regist_capi_new 并存）、部分字段废弃（如 type_desc）、状态码未标准化。

应对策略：

  • 优先使用带 _new 后缀的新字段（如 regist_capi_new）
  • 对 status 和 new_status_code 进行映射清洗，统一为“存续”“吊销”“注销”等标准状态
  • 验证经纬度有效性（如百度 vs 高德坐标系差异）

2. 注册资本的标准化处理

难点：regist_capi_new 为字符串类型（如 “500万元人民币”），含单位、中文数字、货币符号，难以直接用于数值分析。

应对策略：

SELECT 
  eid,
  CASE 
    WHEN regist_capi_new RLIKE '万' THEN 
      CAST(REGEXP_EXTRACT(regist_capi_new, '([0-9\\.]+)万', 1) AS DOUBLE)
    WHEN regist_capi_new RLIKE '亿' THEN 
      CAST(REGEXP_EXTRACT(regist_capi_new, '([0-9\\.]+)亿', 1) AS DOUBLE) * 10000
    ELSE CAST(regist_capi_new AS DOUBLE) / 10000
  END AS regist_capi_in_10k_cny
FROM credit.db_enterpriset_enterprise
WHERE regist_capi_new IS NOT NULL;

3. 企业状态动态追踪

难点：企业可能经历“存续 → 吊销 → 注销”过程，需结合 revoke_date、logout_date、status 多字段判断当前真实状态。

构建指标示例：

  • is_revoked：是否被吊销（revoke_date IS NOT NULL）
  • is_logged_out：是否已注销（logout_date IS NOT NULL）
  • current_status：优先级：注销 > 吊销 > 存续

4. 地理可视化适配

难点：同时存在百度与高德坐标，需统一坐标系以适配地图 API（如高德地图要求 GCJ-02）。

建议：优先使用 gd_longitude / gd_latitude，缺失时用百度坐标转换（需调用坐标转换服务）。

三、实战案例：区域企业信用健康度仪表盘

目标

构建省级企业信用健康度看板，包含：企业总数、异常企业占比、平均注册资本、异常企业地理热力图。

关键指标 SQL

WITH enterprise_status AS (
  SELECT 
    province,
    eid,
    CASE 
      WHEN logout_date IS NOT NULL THEN '注销'
      WHEN revoke_date IS NOT NULL THEN '吊销'
      WHEN new_status_code IN ('1', 'A') THEN '存续' 
      ELSE '其他'
    END AS current_status
  FROM credit.db_enterpriset_enterprise
  WHERE province IS NOT NULL
)
SELECT 
  province,
  COUNT(*) AS total_enterprises,
  SUM(CASE WHEN current_status IN ('吊销', '注销') THEN 1 ELSE 0 END) AS abnormal_count,
  ROUND(
    SUM(CASE WHEN current_status IN ('吊销', '注销') THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2
  ) AS abnormal_rate_percent
FROM enterprise_status
GROUP BY province
ORDER BY abnormal_rate_percent DESC;
-- 2. 各省平均注册资本（万元）
SELECT 
  province,
  AVG(regist_capi_in_10k_cny) AS avg_regist_capi_10k
FROM (
  -- 此处嵌入上文注册资本标准化逻辑
) t
WHERE regist_capi_in_10k_cny > 0
GROUP BY province;

可视化建议

  • 地图热力图：用 abnormal_rate_percent 作为颜色深浅依据
  • 柱状图：展示各省 avg_regist_capi_10k
  • 卡片指标：全国异常企业总数、占比

四、总结

企业征信指标构建的核心在于：数据清洗标准化 + 业务逻辑映射 + 多维动态关联。本案例展示了如何从原始表出发，解决字段歧义、非结构化数据解析、状态动态判断等挑战，最终输出可落地的可视化指标。

建议在实际项目中建立企业状态判定规则引擎和注册资本解析函数，提升指标复用性与准确性。
